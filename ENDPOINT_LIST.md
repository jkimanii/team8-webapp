| Method | Path | Purpose | Maps to Need |
|---|---|---|---|
| GET | `/listings?category={wellness\|counseling}` | Return marketplace listings filtered by category — wellness items or health & counseling service listings | "Group 9 needs read-only access to wellness category listings ... to recommend relevant self-care or over-the-counter items." **and** "Gropup 9 needs read-only access to health & counseling service listings ... to surface available on-campus doctors and counselors." |
| GET | `/listings/{id}` | Return full details for a single listing — used to check current price/stock/availability on a specific listing before recommending it | Companion single-item endpoint to the filtered list above; supports the "must reflect the latest marketplace data at request time" requirement from Strathmore Mental Health App's memo. |
| PATCH | `/listings/{id}/availability` | Update a listing's availability status when a booking action in Strathmore Mental Health App's system consumes it — e.g. a doctor accepting an appointment tied to a counseling listing, or a wellness item being claimed | "Group 9 needs to update a listing's availability status when a booking action in their own system consumes it ... in order to keep StrathShop listings accurate, without requiring full edit access to the listing or any student-identifying information." |
| GET | `/categories` | Return the list of available marketplace categories (id, label) | "Group 9 needs read-only access to the list of available marketplace categories ... to know which category values are valid when filtering listings." |
| GET | `/categories/{id}` | Return a single category's details by ID — useful if Strathmore Mental Health App stores just a category ID and needs to resolve its display label | Companion single-item endpoint to the categories list above. |
